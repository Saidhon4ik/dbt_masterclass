dbt Masterclass
A hands-on Data Engineering learning project focused on dbt Core, SQL transformations, DuckDB, Python and modern analytics engineering practices.
Learning objectives
- Understand dbt architecture and fundamentals.
- Build SQL transformation models.
- Implement staging, intermediate and mart layers.
- Learn data testing and documentation.
- Develop incremental models and snapshots.
- Practice production-oriented workflows.
Technology stack
- Python
- uv
- dbt Core
- DuckDB
- Git and GitHub
Learning stages
1. Junior — Fundamentals and basic transformations.
2. Middle — Advanced transformations and optimization.
3. Senior — Architecture, CI/CD and production practices.
